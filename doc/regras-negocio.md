# Regras de Negócio

| RNs | Descrição |
| --- | --------- |
| RN 1 | O nome de usuário usado para fazer login deve ser único no sistema. |
| RN 2 | A confirmação de senha deve ser igual a senha no cadastro. |
| RN 3 | O feed deve apresentar as publicações de outros usuários, organizadas em ordem decrescente de data, das mais recentes para as mais antigas. |
